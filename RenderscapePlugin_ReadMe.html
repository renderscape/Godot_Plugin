Requirements

Engine
Godot 4.x
Tested on 4.2+
Account
Renderscape.io login
At least one purchased asset
This plugin is pure GDScript — unlike the Unreal version, there's nothing to compile. No Visual Studio, no build step, no C++ toolchain. Install the folder, enable it, done.

Install — Asset Library Recommended

1

Open the AssetLib tab

In the Godot editor, click the AssetLib tab along the top of the window (next to 2D, 3D, and Script).

2

Search and download

Search for Renderscape, click into the listing, then click Download followed by Install.

3

Enable the plugin

Go to Project → Project Settings → Plugins and toggle Renderscape on.

Install — Manual

1

Download or clone the repository

Grab the latest release, or clone the repo directly.

2

Copy the plugin folder into your project

Copy addons/renderscape/ into your project's own addons/ directory, so it looks like this:

your_project/ ├── addons/ │ └── renderscape/ │ ├── plugin.cfg │ ├── renderscape_node.gd │ ├── renderscape_panel.gd │ └── ... └── project.godot
3

Enable the plugin

Go to Project → Project Settings → Plugins and toggle Renderscape on.

Getting started

1

Open the Renderscape dock

It docks to the left side of the editor by default, alongside FileSystem and Scene.

2

Log in

Enter your Renderscape.io email and password. Credentials are encrypted locally, so you won't need to log in again next session.

3

Pull in your assets

Click Get My Assets to load everything you've purchased into the panel.

Features

Search & filter

Free-text search plus category chips to narrow your library fast.

Sort & view

Newest-first or A→Z, and toggle between list and grid layouts.

Quality tiers

Production, Medium, or Low Poly — each tier downloads and caches separately.

Drag & drop

Drag a downloaded asset straight from the panel into your 2D/3D viewport.

New asset alerts

The panel checks for new purchases automatically and flags them.

Security

Local credential storage

Saved email/password are encrypted with AES-256-CBC before being written to disk, using a key derived from your project identity. This isn't OS-keychain-grade security, but it stops the file from being plaintext-readable.

Session tokens

Your auth token is kept in memory only for the duration of the editor session — it's never written to disk.

Customizing

Refresh interval

In renderscape_panel.gd, on the refresh_timer:

gdscript
# Change 120.0 to any interval in seconds
refresh_timer.wait_time = 120.0 # 2 minutes

Download directory

In renderscape_panel.gd:

gdscript
const ASSET_DIR := "res://renderscape_assets"

UI colors

In renderscape_style.gd:

gdscript
# Title color
const TITLE_COLOR := Color(0.5, 0.8, 1.0, 1.0)
# New asset badge + active category chip
const ACCENT_COLOR := Color(0.15, 0.35, 0.75, 1.0)

Troubleshooting

Plugin doesn't appear in Project Settings → Plugins
Check that plugin.cfg is directly inside addons/renderscape/ and not in a subdirectory. Restart the editor after fixing the path.
Login fails
Open the Output panel and look for HTTP errors. Verify your credentials are correct on renderscape.io, and check your internet connection. If saved credentials seem stuck, log out and log back in to overwrite them.
Download fails
Confirm the asset actually shows as purchased on your renderscape.io account page. If it does and the download still fails, check the Output panel for the response code and try again in a minute — the request may have timed out.
Thumbnails don't load
Non-critical — asset names and all other functionality still work correctly. Thumbnails load asynchronously after the asset list. Check your internet connection if they never appear.
Asset downloads but won't import, or looks wrong
Godot 4 doesn't natively support Draco-compressed .glb files. Assets served through this plugin are delivered uncompressed specifically for engine compatibility, so this is rare — but if it happens, make sure you're on the latest version of the plugin and try re-downloading the asset.
Drag-and-drop doesn't place the asset
Make sure the asset has finished downloading first — look for the [⬇ downloading] tag next to it in the list. Once it disappears, dragging from the panel into the viewport will work.
